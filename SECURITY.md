# Security Policy

## Scope

This repository contains an open-source football simulation engine. Do not include credentials, private datasets, personal records, live account data, or unrelated workspace files in issues or pull requests.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository when available. If it is unavailable, contact the repository owner through the contact method listed on the GitHub profile. Do not publish exploit details or sensitive information in a public issue.
