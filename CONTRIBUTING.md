# Contributing

Thanks for helping improve the football simulation engine.

- Keep M1 football-only. Do not add odds, prices, betting lines, trading signals, P&L, or execution data to its inputs or runtime dependencies.
- Keep changes narrow and explain the simulator behavior or contract that changes.
- Add or update focused tests for code changes. Never represent a passing test as empirical model validation.
- Preserve causal input cutoffs and unknown identity states. Do not silently substitute a player, starter, or data source.
- Do not commit credentials, environment files, private datasets, personal records, raw account data, or generated run outputs.
- Describe the cohort and evidence behind any performance claim. Do not claim profitability based on simulator metrics.

By submitting a contribution, you agree that it may be distributed under this repository's MIT License.
